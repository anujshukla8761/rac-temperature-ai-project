# Dataset information

- `sample_temperature_data.csv`: simulated demonstration data, generated by `python -m rac_ai.synthetic`. It is **not real sensor data** and should not be described as an experiment.
- `real_data_template.csv`: header-only CSV template for actual readings. Use the manual logger or enter measured values using these column names.

Recommended interval: every 5 minutes. Keep timestamps consistent, use one row per timestamp, and do not fill missing measurements with invented values. Record temperature in degrees Celsius, humidity in percent, occupancy as a nonnegative integer, `ac_running` as 0/1, and `ac_runtime_min` as minutes since the present continuous AC ON period began (0 when off).

CSV validation also rejects missing/non-numeric or infinite measurements, duplicate timestamps, humidity outside 0–100%, implausible configured temperature/setpoint ranges, invalid AC ON/OFF flags, fractional/negative occupancy, and nonzero AC runtime while the AC is off. These checks catch likely input mistakes; they do not replace sensor calibration or engineering review.
